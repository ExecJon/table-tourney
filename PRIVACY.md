# Privacy Policy – Table Tourney

_Last updated: June 20, 2026_

Table Tourney respects player privacy and tries to collect only the data needed to run the app, improve reliability, support optional account features, and keep development sustainable.

## Data Stored Locally

Table Tourney can be used without creating an account. When used locally, player names, decks, matches, tournament records, score history, and other user-created content are stored on the user's device.

Local data is not uploaded to Table Tourney cloud services unless the user signs in and uses cloud/account features that require syncing or sharing.

## Table Tourney Accounts and Cloud Features

If a user creates a Table Tourney account, Table Tourney may store account-related data using Google Firebase services.

Account and cloud data may include:

- Sign-in identifier from Apple or Google
- Email address provided by the sign-in provider
- Display name
- Player ID
- Avatar selection
- Player colors
- Friend requests
- Friend relationships
- Public player profile data
- Player Showcase visibility settings
- Shared profile information selected by the user
- Shared deck/profile/history data when cloud features are used
- Event reward and cosmetic unlock status

Table Tourney accounts are used to support features such as My Profile, friend search, friend requests, Player Showcase, shared history, event rewards, and future sync support.

Users control what accepted friends can see through account sharing settings. Decks, match record, favorite formats, and recent activity can be shown or hidden.

## Player Showcase

Player Showcase lets accepted friends view selected parts of a user’s Table Tourney profile on their own devices.

Depending on the user’s sharing settings, a showcase may include:

- Display name
- Player ID
- Avatar
- Player colors
- Match record
- Favorite game or format
- Recent activity
- Shared decks

Player Showcase is intended for friend-to-friend visibility inside Table Tourney.

## Analytics

Table Tourney uses Firebase Analytics to understand how the app is used and to improve features, reliability, and performance.

Analytics may include:

- App usage and interaction data
- App version
- Device type
- Operating system
- Language
- General geographic region
- A pseudonymous app installation identifier
- Gameplay categories such as TCG, format, event type, match format, and player count
- Ad banner load, failure, and impression events

Table Tourney does not intentionally send player names, deck names, tournament names, match results, winners, or other user-entered gameplay content to Firebase Analytics.

## Advertising

Table Tourney uses Google AdMob to show banner ads to free users on the home screen.

Ads are not shown during active matches, tournaments, score entry, game setup, or gameplay. PRO and Founder users do not see ads.

AdMob and related Google services may collect or process data such as:

- Device and app information
- Advertising or app identifiers where available
- IP address
- General location
- Ad interactions
- Ad impression and performance data

This data is used to load, measure, limit, and improve ads. Google processes advertising data according to its own privacy policies and advertising terms.

Table Tourney does not sell personal information.

## Firebase Remote Config and Live Events

Table Tourney uses Firebase Remote Config and Firebase cloud services to support live app configuration.

This may include:

- Enabling or disabling ads
- Updating event availability
- Managing Comic Clash Weekend timing
- Supporting event rewards and cosmetic unlocks
- Adjusting app behavior without requiring a full app update

Remote Config may use a Firebase installation identifier to provide the correct configuration to a device.

## Comic Clash Weekend and Event Rewards

Table Tourney may offer limited-time in-app events, such as Comic Clash Weekend.

Participation in an event may unlock in-app rewards such as avatars, HUD themes, or cosmetic licenses. Event participation and reward state may be stored with the user’s Table Tourney account when account features are used.

If users choose to share Comic Clash games on X and tag `@TableTourney`, that sharing happens outside Table Tourney and is subject to X’s own privacy policy. Public posts may be used by Table Tourney to administer giveaways, including chances to unlock PRO for free.

Participation in social sharing or giveaways is optional.

## Sign-In Providers

Table Tourney supports sign-in with Apple and Google.

Apple and Google may process sign-in information according to their own privacy policies. Table Tourney receives only the information needed to create and manage the user’s Table Tourney account, such as a sign-in identifier and, when provided, an email address or display name.

## Data Deletion and Export

Table Tourney includes account export and account deletion support.

Deleting a Table Tourney cloud account removes cloud account data controlled by Table Tourney, including cloud profile, friend, claim, and cloud-owned account records. Local data stored on the device may remain unless deleted separately by the user.

Some third-party providers may retain limited logs or backups for a period of time according to their own policies.
